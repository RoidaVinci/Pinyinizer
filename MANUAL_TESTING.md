# Manual Testing

## Verify translation with Pinyin

1. Load the extension via `chrome://extensions` using *Load unpacked*.
2. Open the options page and enable **Chinese (with Pinyin)**.
3. Visit a page containing Chinese text.
4. Confirm each translated segment displays:
   - the original characters,
   - Pinyin above the text, and
   - the translation stacked with the Pinyin.
5. Disable **Chinese (with Pinyin)** and reload the page to ensure only translations appear.
